# ✅ ToDo List com React + Recoil

Aplicação de lista de tarefas desenvolvida para praticar gerenciamento de estados no React utilizando **Recoil**. O projeto possui funcionalidades completas de um CRUD, permitindo criar, editar, excluir e controlar o status das tarefas.

## 🚀 Demonstração

> Projeto desenvolvido como prática de React, focando em manipulação de estados, arrays, componentes e gerenciamento global de dados.

---

## 📌 Funcionalidades

✅ Adicionar novas tarefas  
✅ Listar tarefas cadastradas  
✅ Editar tarefas existentes  
✅ Excluir tarefas  
✅ Marcar tarefas como concluídas  
✅ Alternar status das tarefas (concluída/pendente)  
✅ Filtrar tarefas por:
- Todas
- Pendentes
- Concluídas

---

- React

## 📚 Conceitos praticados

Durante o desenvolvimento foram aplicados conceitos importantes do React:

- Componentização
- Hooks:
  - `useState`
  - `useRecoilState`
- Gerenciamento de estado global com Recoil
- Manipulação de arrays:
  - `map()`
  - `filter()`
- Renderização dinâmica de listas
- Eventos:
  - `onClick`
  - `onChange`
- Controle de inputs
- Atualização imutável de estados
- Criação de objetos com propriedades dinâmicas
